# Setup Instructions

## JDK Version

The project was compiled with JDK `21.0.12.1`. Confirm the installed Java runtime and compiler with:

```text
java -version
javac -version
```

## Hello World Run

A Java class with a `main` method can print a message with `System.out.println("Hello, World!")`. Save it as `HelloWorld.java`, compile it with `javac HelloWorld.java`, then run it with `java HelloWorld`. The program prints `Hello, World!` to the console.

## LearnTrack

From the project directory, compile the source files into `bin` using the commands in the project README. Start the application with:

```text
java -cp bin com.airtribe.learntrack.Main
```
