# JVM Basics

The JDK is the Java Development Kit and includes tools such as the compiler used to build Java programs. The JRE provides the libraries and runtime needed to run Java programs. The JVM, or Java Virtual Machine, runs Java bytecode. Bytecode is the platform-independent output produced when Java source code is compiled.

“Write once, run anywhere” means that compiled Java bytecode can run on any operating system that has a compatible JVM. The same compiled program can therefore be used on different systems without compiling its source code separately for each one.
